# frontend-skills-checklist

An interactive landing page that turns the front end developer skills checklist into a live job ready meter. Tick off skills across HTML, CSS, JavaScript, frameworks, design, tools and interview prep, switch between three visual looks, and jump to related courses and blogs.

## Features

- Live job ready meter that updates as you tick skills
- Three switchable looks: Sunny, Night and Blueprint
- Filter the checklist by category
- Progress saved in your browser with localStorage
- Responsive layout, keyboard friendly, respects reduced motion
- Single file, no build step, no dependencies

## Run it locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Go to Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and the `/ (root)` folder, then save.
4. Your site goes live at `https://<your-username>.github.io/frontend-skills-checklist/`.
